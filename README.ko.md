# SquirrelTranslate

macOS의 Squirrel(Rime)을 위한 번역 및 빠른 검색 패널입니다. 후보 번역, IP 및 전화번호 지역 조회, 날짜·시간·단위 변환, 색상 도구를 제공합니다.

언어: [简体中文](./README.md) · [繁體中文](./README.zh-Hant.md) · [English](./README.en.md) · [한국어](./README.ko.md) · [日本語](./README.ja.md)

제품 소개 페이지: [SquirrelTranslate](https://owllinker.github.io/SquirrelTranslate/)

## 핵심 기능 데모

아래 애니메이션은 U 패널 디자인을 바탕으로 한 사용 예시이며 실제 화면 녹화가 아닙니다. 전화번호와 로컬/공인 IP는 가렸고, 지정 IP 예시는 `8.8.8.8` 조회 결과를 보여줍니다.

**후보 번역:** `u`와 병음을 입력해 후보, 번역, 사용 가능한 발음을 표시합니다.

![후보 번역 데모](./docs/assets/translation.gif)

**IP 조회:** `uip`와 전체 IPv4 주소를 입력해 지역과 네트워크 제공자를 조회합니다.

![IP 조회 데모](./docs/assets/ip-lookup.gif)

**전화번호 지역:** 전화번호를 입력해 로컬 번호 대역의 지역과 통신사를 표시합니다. 데모 번호는 가려져 있습니다.

![전화번호 지역 데모](./docs/assets/phone-region.gif)

## Squirrel 일반 후보 패널

Squirrel 후보 패널이 표시될 때 아래 단축키를 사용할 수 있습니다. 일반 텍스트 입력은 Squirrel과 현재 Rime 스키마가 계속 처리합니다.

| 단축키 | 기능 |
| --- | --- |
| `⌃T` | 후보 번역 켜기/끄기 |
| `⌃P` | 선택한 번역 읽기; 번역이 준비되지 않았으면 원문을 읽지 않음 |
| `⌃Y` | 선택한 후보의 번역 입력 |
| `⇧^` | 전체 뜻과 발음 기호 펼치기/접기 |
| `⇧P` | 발음 기호 표시 켜기/끄기 |
| `⌃G` / `⌃B` | 기본/두 번째 검색 엔진으로 선택 후보 검색 |
| `⌘,` | 단축키 도움말 열기/닫기 |

중국어 후보는 영어로, 영어 후보는 중국어로 번역하며, 제공되는 경우 발음 기호도 표시합니다. 이모지 이름은 로컬 데이터를 사용하며 온라인 번역 서비스로 전송하지 않습니다. 후보 번호와 페이지 이동은 현재 Squirrel 스키마 설정을 따릅니다. 기본 검색 엔진은 Google, 두 번째는 Bing입니다. `u<엔진>1`로 `⌃G`, `u<엔진>2`로 `⌃B` 엔진을 설정할 수 있습니다(예: `ubing1`, `ugoogle2`, `ubaidu2`). Google, Bing, Baidu, DuckDuckGo, Yahoo, Brave, Sogou, Yandex를 지원하며 설정은 로컬에 저장됩니다.

## `u` 조회 패널

Squirrel 간체 중국어 입력 소스가 활성화되어 있고 편집 가능한 입력란에 포커스가 없을 때 소문자 `u`를 입력하면 패널이 열립니다. 이어서 병음이나 도구 명령을 입력하세요. 편집 입력란에서는 키 입력을 가로채지 않습니다. 입력 줄에는 `uni hao`, `uconv5`처럼 `u` 접두사가 표시됩니다. 접두사는 모드 표시일 뿐 병음, 검색, 복사 내용에는 포함되지 않습니다. 패널은 Rime 세션의 후보를 사용하며 입력을 멈춘 뒤 약 300ms 후 번역과 발음을 조회합니다. 번역은 macOS 사전을 우선 사용하고, 이후 설정 순서대로 활성화된 온라인 제공자를 시도하여 첫 성공 결과를 표시합니다.

### 패널 조작

| 단축키 | 기능 |
| --- | --- |
| `↑` / `↓` | 후보 선택 이동; 페이지 끝에서 다음 페이지로 이동 |
| `←` / `→`, `PageUp` / `PageDown` | 페이지 이동 |
| 현재 스키마 페이지 키 | 인식 가능한 `key_binder/bindings` 사용; `-`, `=`는 패널 페이지 키로 사용하지 않음 |
| `⌘C` | 선택 항목의 결과 정보 복사 |
| Space | 현재 후보 복사; 색상 모드에서는 색상 확정/다시 샘플링 |
| `⌘V` | 클립보드 내용을 조회 문자열 뒤에 추가 |
| `⌘,` 또는 오른쪽 아래 `ⓘ` | 도움말 열기/닫기; 도움말에서 화살표로 페이지/항목 이동 |
| `Esc` | 도움말 닫기; 색상 모드에서는 돋보기를 먼저 닫고 패널 닫기 |
| Backspace | 마지막 입력 문자 삭제 |

숫자와 문장부호는 후보 선택이 아니라 조회 입력입니다. 유효한 8자리 날짜는 날짜 변환으로 자동 전환됩니다. 도구 결과는 페이지당 최대 9개입니다. 후보는 한 줄로 유지하고 결과는 줄바꿈됩니다. 패널 기본 최대 너비는 400pt이며 `umaxwidth숫자`로 200–2000pt 범위에서 설정할 수 있고, 입력을 약 1초 멈추면 저장됩니다.

### 명령어

모든 명령은 `u`로 시작하며, 명령 뒤에 매개변수를 바로 입력합니다. `:` 또는 `=`는 사용하지 않습니다. Backspace로 수정하거나 긴 문자열은 `⌘V`로 붙여 넣으세요.

| 예시 | 기능 및 결과 |
| --- | --- |
| `unihao` | 조회 세션의 기본 Rime 스키마로 중국어 후보, 번역, 발음 표시 |
| `ucolor`, `uyanse` | 시스템 색상 돋보기와 결과 패널을 엽니다. 방향키로 샘플 지점을 물리 픽셀 하나씩 이동하고 Space 또는 클릭으로 색상을 확정해 돋보기를 닫습니다. Space로 다시 샘플링할 수 있습니다. 화면 기록 권한은 사용하지 않으며 확대율은 macOS가 제어합니다. |
| `ucolorRRGGBB`, `ucolor#RRGGBB` | `#` 유무 HEX, 알파 HEX, RGB(A), HSL(A), HSV(A)로 변환하고 `rgb(255,0,0)`, `rgba(255,0,0,0.5)`도 허용합니다. 화살표로 형식을 선택하고 `⌘C`로 값을 복사합니다. |
| `utime` | 입력 순간의 현지 시간대 시간, UTC, Unix 타임스탬프를 고정 표시 |
| `utime1727683200`, `utime1727683200000` | Unix 초/밀리초를 날짜와 시간으로 변환 |
| `utimeAsia/Tokyo` | 유효한 시간대의 현재 시간 표시 |
| `utimeniuyue`, `utimedongjing` | 도시 병음으로 뉴욕 또는 도쿄 시간을 조회합니다. 패널은 이 Mac의 현지 도시/시간대 시간도 베이징 시간처럼 이름을 붙여 표시합니다. 도시 입력은 병음만 지원하며, 유효한 IANA 시간대 ID도 입력할 수 있습니다. 다른 병음 별칭은 `lundun`, `luoshanji`, `jiujinshan`, `zhijiage`, `bali`, `shouer`, `xinjiapo`, `xianggang`, `taibei`, `xini`, `aokelan`, `beijing`, `shanghai`, `dibai`입니다. |
| `udate20261002`, `udate2026-10-02` | 지난 날짜 수/남은 날짜 수/오늘과 시작·종료 날짜 표시 |
| `udate20261001.20261002` | 두 날짜 사이 일수와 시작·종료 날짜 표시; 날짜는 `.`, `-`, 공백 하나로 구분 |
| `uconv5`, `uconv5.5` | 길이, 질량, 온도, 부피, 압력, 전기량의 일반 변환 목록 표시; 지정되지 않은 입력 단위는 추측하지 않음 |
| `uconv5mi`, `uconv72f`, `uconv5kg` | 지정한 단위 범주 내에서 변환(길이, 질량, 부피, 온도 등) |
| `uconv1000pa`, `uconv1kpa`, `uconv1mpa`, `uconv760mmhg`, `uconv1kgf/cm2` | 압력 결과에 층수 추정, 층고 설정, 정압 설정 3개 행을 표시합니다. 층수는 압력과 층고로 직접 계산하며 정압을 빼지 않습니다. `mp`/`mpa` 뒤의 `1`은 1급 고층, `2`는 2급 고층/다층이며 숫자가 없거나 다른 숫자면 기타 건축물(3)입니다. 숫자를 명시한 경우에만 추정 결과에 분류를 표시합니다. |
| `uconv3mH2O`, `uconv3floor` | 수주 높이 또는 층수에서 이론 압력을 계산합니다. 기본 층고는 3.0m이며 실제 건물의 급수 능력을 예측하지 않습니다. |
| `uconv220v`, `uconv2a`, `uconv500w`, `uconv10kohm`, `uconv1kwh`, `uconv60hz`, `uconv100uf` | 전압, 전류, 전력, 저항, 에너지, 주파수, 정전용량, 인덕턴스, 전하를 동일한 물리량 범주 안에서 변환합니다. 회로 공식을 추정 적용하지 않습니다. `mW`/`MW`, `mWh`/`MWh`처럼 SI 대소문자 구분 기호는 구분합니다. |
| `uconv100rmb`, `uconv100usa`, `uconv100jp`, `uconv100uk` | 주요 통화를 환산합니다. 날짜가 포함된 일일 참고 환율이며 실시간 거래 시세가 아닙니다. 네트워크에는 통화 코드만 전송하고 입력 금액은 전송하지 않습니다. 별칭: `rmb/cn`, `usa/us`, `jp`, `uk`. |
| `uip` | 로컬 IP를 표시하고 공인 IP, 지역, ISP를 조회합니다. 네트워크가 필요하며 공인 IP를 조회 서비스에 전송합니다. |
| `uip8.8.8.8` | 잠시 입력을 멈추면 해당 IPv4의 대략적인 지역과 사업자를 조회합니다. IP는 조회 서비스로 전송됩니다. |
| `u132...`, `uphone132...` | 중국 본토 번호 앞자리 지역을 식별합니다. 11자리 전체 번호는 로컬 번호 대역 데이터로 지역과 통신사를 표시합니다. 실제 위치나 현재 통신사는 알 수 없습니다. |
| `u+86 171 6772 6019`, `u+86 (21) 6349 3582` | iPhone에서 복사한 국제 형식 휴대전화/유선전화 번호를 조회합니다. 공백, 하이픈, 중국식/영문 괄호를 지원하며 `u021-20422661`, `u02120422661`, `u（021）20422661`, `u(021)20422661`도 가능합니다. 로컬 번호 대역/지역 번호 데이터만 사용하고 번호를 업로드하지 않습니다. 잘못되거나 너무 긴 번호는 거부합니다. |
| `umaxwidth600` | 패널 최대 너비를 600pt로 설정(범위 200–2000, 기본 400); 화면 여유 공간에 따라 더 좁아질 수 있음 |
| `ufloorheight3.2` | 층고 설정: `ufloorheight3.2 (3.2: 층고; 설정 범위 2–12m; 기본 3m)` |
| `ufiredefault1-0.15` | 1번 소방 정압 참고값을 0.15MPa로 설정합니다. 1–3번, 0 초과 2.4MPa 이하. 3번의 0.01MPa는 규정값이 아닌 사용자 참고값입니다. |
| `ulangzh`, `ulangtw`, `ulangen`, `ulangko`, `ulangja` | U 패널을 중국어 간체·번체, 영어, 한국어 또는 일본어로 전환합니다. 기능 이름, 결과 설명, 도움말, 오류 및 상태 메시지도 선택한 언어로 표시됩니다. `ulang`으로 옵션을 확인합니다. |

### 호환성과 제한

이 프로젝트는 범용 텍스트 입력 대체기가 아니라 Squirrel 프로세스 내 플러그인입니다. 문서화된 대상은 macOS 26.6.2, Squirrel 1.1.2(번들 librime 1.17.0), 간체 입력 소스 `im.rime.inputmethod.Squirrel.Hans`입니다. 빌드 목표는 macOS 13 이상 및 Universal arm64/x86_64이지만 다른 macOS 버전은 종단 간 검증되지 않았습니다. 후보 조회는 `~/Library/Rime/default.yaml`의 기본 스키마를 사용합니다. 이름이 지정된 타사 스키마는 개별 검증되지 않았으므로 다른 버전, 입력 소스, 스키마의 호환성을 가정하지 마세요.

| 기능 | 호환 조건 |
| --- | --- |
| `u` 패널 열기 | 지정된 Squirrel 간체 입력 소스에서 편집란 밖에 소문자 `u`를 입력해야 하며 Squirrel 앱에 손쉬운 사용 권한이 필요합니다. |
| 병음 후보 및 번역 | 별도 Rime 세션과 `default.yaml`의 기본 스키마를 사용합니다. 임시로 선택한 스키마가 이어진다고 보장하지 않으며, 이름이 지정된 타사 스키마는 검증되지 않았습니다. |
| 방향키 및 스키마 페이지 키 | 패널 방향키와 PageUp/PageDown은 패널을 탐색합니다. 사용자 정의 페이지 키는 조회 세션이 해당 바인딩을 읽을 수 있을 때만 동작하며 기본 스키마가 아닌 키는 보장되지 않습니다. |
| 날짜/시간, 단위, 색상 형식, 너비, 전화번호/지역 도구 | 패널이 열린 뒤 조회 브리지가 로컬 처리합니다. 위 Squirrel/macOS/입력 소스 조건은 동일하게 적용됩니다. 색상 선택은 시스템 색상 선택기를 사용하며 화면 기록 권한이 필요하지 않습니다. |
| IP, 환율, 온라인 번역, 웹 검색 | 네트워크와 각 서비스 상태에 따라 달라집니다. 온라인 번역에는 제공자 설정도 필요합니다. |

빌드 또는 단위 테스트의 성공이 문서에 없는 환경의 종단 간 호환성을 의미하지는 않습니다.

## 설치

### 최신 사전 빌드 미리보기

[최신 Release에서 macOS Universal 패키지 다운로드](https://github.com/OwlLinker/SquirrelTranslate/releases/latest). 공개 쿼리 브리지, URL 도우미, 설치 스크립트, 문서 및 사전 빌드 결과물이 포함되며 비공개 번역 통합은 포함되지 않습니다.

Apple Developer ID 서명과 공증은 없습니다. macOS 보안 경고가 표시될 수 있습니다. 설치하려면 유효하고 안정적인 로컬 코드 서명 ID가 필요하며 Squirrel 손쉬운 사용 권한을 요청할 수 있습니다. macOS 26.6.2 (Apple Silicon)에서 빌드하고 Squirrel 1.1.2에서 검증했습니다. arm64 및 x86_64 바이너리를 포함하지만 다른 macOS, Squirrel, Rime 스키마 조합은 검증되지 않았습니다. 공개 빌드, 단위 변환 및 공개 제공자 파서 테스트를 통과했습니다.

**설치 순서:** ZIP을 다운로드해 압축을 푼 다음 중국어 [상세 설치 안내](./README.md#安装-u-面板)를 따르세요. 환경 확인, 서명 ID 준비, 기존 독립 입력 바 종료(사용 중인 경우) 후 빌드 도구 준비와 4단계(빌드)만 건너뛰고 5단계(설치), 권한 설정 및 확인을 진행합니다. 압축을 푼 프로젝트 폴더에서 명령을 실행하세요. 원클릭 설치 프로그램이 아닙니다.
