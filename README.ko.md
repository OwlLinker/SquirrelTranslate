# SquirrelTranslate

macOS의 Squirrel(Rime)을 위한 번역 및 빠른 검색 패널입니다. 후보 번역, IP 및 전화번호 지역 조회, 날짜·시간·단위 변환, 색상 도구를 제공합니다.

언어: [简体中文](./README.md) · [繁體中文](./README.zh-Hant.md) · [English](./README.en.md) · [한국어](./README.ko.md) · [日本語](./README.ja.md)

## 주요 기능

- Rime 후보를 번역하고 사용 가능한 발음 기호를 표시합니다.
- 입력 가능한 필드 밖에서 `u` 패널을 열어 번역과 도구를 사용할 수 있습니다.
- IP 위치 및 중국 전화번호 지역을 조회하고 날짜, 시간, 단위, 색상을 변환합니다.
- macOS 사전, Google, Bing, DeepL API를 번역에 사용합니다.

## 패널 언어 설정

`u` 패널에 다음 명령을 입력하면 즉시 언어가 바뀌고 확인 메시지가 표시되며 설정이 저장됩니다.

| 명령 | 언어 |
| --- | --- |
| `ulangzh` | 중국어 간체 |
| `ulangtw` | 중국어 번체 |
| `ulangen` | 영어 |
| `ulangko` | 한국어 |
| `ulangja` | 일본어 |

`ulang`을 입력하면 언어 옵션을 볼 수 있습니다. 이 설정은 인터페이스와 도움말만 바꾸며 번역 결과나 조회 데이터는 변경하지 않습니다.

## 사용 예

| 입력 | 결과 |
| --- | --- |
| `uip8.8.8.8` | IP 지역 및 네트워크 제공자 |
| `u132...` 또는 `uphone...` | 중국 본토 전화번호 지역 조회 |
| `udate20261002` | 오늘을 기준으로 날짜 계산 |
| `utime1727683200` | Unix 타임스탬프 변환 |
| `uconv1000pa` | 압력 등을 포함한 단위 변환 |
| `ucolorRRGGBB` | HEX/RGB/HSL/HSV 색상 형식 변환 |
| `umaxwidth600` | 패널 최대 너비 설정 |

## 설치 및 호환성

자세한 [설치 안내](./README.md#설치-u-面板), 호환성 표, 권한, 번역 제공자 설정 및 문제 해결은 중국어 README를 참고하세요. 현재 문서에 명시된 macOS, Squirrel 및 Rime 조합만 검증 대상으로 취급하세요.

macOS의 Squirrel이 필요하며, Squirrel 앱에 손쉬운 사용 권한을 허용해야 합니다. 색상 선택에는 화면 기록 권한이 필요하지 않습니다. 온라인 기능은 네트워크 연결이 필요합니다.
