# SquirrelTranslate

macOS の Squirrel（Rime）向け翻訳・クイック検索パネルです。候補翻訳、IP と電話番号の地域検索、日付・時刻・単位変換、色ツールを提供します。

言語: [简体中文](./README.md) · [繁體中文](./README.zh-Hant.md) · [English](./README.en.md) · [한국어](./README.ko.md) · [日本語](./README.ja.md)

## 主な機能のデモ

以下は U パネルのデザインに基づく操作例で、実機の画面録画ではありません。電話番号とローカル／パブリック IP はマスキングしています。指定 IP の例では `8.8.8.8` の検索結果を表示します。

**候補翻訳:** `u` とピンインを入力し、候補、訳、利用可能な発音記号を表示します。

**IP 検索:** `uip` と完全な IPv4 アドレスを入力し、地域とネットワーク事業者を検索します。

## Squirrel の通常候補パネル

Squirrel の候補パネル表示中に以下のショートカットを使用できます。通常の文字入力は引き続き Squirrel と現在の Rime スキーマが処理します。

| ショートカット | 機能 |
| --- | --- |
| `⌃T` | 候補翻訳の切り替え |
| `⌃P` | 選択中の訳を読み上げる（訳が未準備なら原文は読み上げない） |
| `⌃Y` | 選択候補の訳を入力 |
| `⇧^` | 完全な語義と発音記号の展開／折りたたみ |
| `⇧P` | 発音記号表示の切り替え |
| `⌃G` / `⌃B` | 既定／第2検索エンジンで選択候補を検索 |
| `⌃N` | 既定ブラウザ経由でニュース拡張機能から検索 |
| `⌘,` | ショートカットヘルプの切り替え |

中国語候補は英語へ、英語候補は中国語へ翻訳し、利用可能な場合は発音記号も表示します。絵文字名はローカルデータを使用し、オンライン翻訳サービスには送信しません。候補番号とページ移動は現在の Squirrel スキーマに従います。既定の検索エンジンは Google、第2検索エンジンは Bing です。`u<engine>1` で `⌃G`、`u<engine>2` で `⌃B` の検索先を設定できます（例: `ubing1`、`ugoogle2`、`ubaidu2`）。Google、Bing、百度、DuckDuckGo、Yahoo、Brave、Sogou、Yandex に対応し、設定はローカルに保存されます。

## `u` クイック検索パネル

Squirrel の簡体字中国語入力ソースが有効で、編集可能な入力欄にフォーカスがないとき、小文字 `u` を入力するとパネルが開きます。その後、ピンインまたはツールコマンドを入力します。入力欄内ではキーを横取りしません。入力行には `uni hao`、`uconv5` のように `u` 接頭辞全体を表示します。接頭辞はモード表示用で、ピンイン、検索、コピー内容には含まれません。候補には Rime セッションを使用し、入力停止から約300ms後に翻訳と発音記号を検索します。翻訳は macOS 辞書を優先し、その後は設定順に有効なオンラインプロバイダーを試し、最初に成功した結果を表示します。

### パネル操作

| ショートカット | 機能 |
| --- | --- |
| `↑` / `↓` | 選択候補を移動し、端でページをまたぐ |
| `←` / `→`、`PageUp` / `PageDown` | ページ移動 |
| 現在のスキーマのページキー | 認識可能な `key_binder/bindings` を使用。`-` と `=` はパネルのページ移動に使わない |
| `⌘C` | 選択行の結果情報をコピー |
| Space | 選択候補をコピー。色モードでは色の確定／再サンプリング |
| `⌘V` | クリップボードの文字列を検索入力に追加 |
| `⌘,` または右下の `ⓘ` | ヘルプを開閉。ヘルプ内は矢印でページ／項目を移動 |
| `Esc` | ヘルプを閉じる。色モードでは先に拡大鏡を閉じ、その後パネルを閉じる |
| Backspace | 最後の入力文字を削除 |

数字と句読点は候補選択ではなく検索入力になります。有効な8桁の日付は自動的に日付変換を開始します。ツール結果は1ページ最大9件です。候補名は1行を維持し、結果欄は折り返します。パネル幅の既定上限は400ptで、`umaxwidth数字` により200～2000ptに設定できます。入力停止から約1秒後に保存されます。

### コマンド

すべてのコマンドは `u` で始まり、キーワードの直後にパラメーターを続けます。`:` と `=` は使いません。Backspace で修正でき、長い文字列は `⌘V` で貼り付けられます。

| 例 | 機能と結果 |
| --- | --- |
| `unihao` | クエリーセッションの既定 Rime スキーマで中国語候補、訳、発音記号を表示 |
| `ucolor`、`uyanse` | macOS の色拡大鏡と結果パネルを開きます。矢印キーでサンプル点を物理ピクセル単位で移動し、Space またはクリックで色を確定して拡大鏡を閉じます。Space で再開できます。画面収録権限は使わず、拡大率は macOS が制御します。 |
| `ucolorRRGGBB`、`ucolor#RRGGBB` | `#` あり／なし HEX、アルファ付き HEX、RGB(A)、HSL(A)、HSV(A) に変換。`rgb(255,0,0)`、`rgba(255,0,0,0.5)` も対応。矢印で形式を選び、`⌘C` で値をコピーします。 |
| `utime` | 入力時点のローカル時刻、UTC、Unix タイムスタンプを固定表示 |
| `utime1727683200`、`utime1727683200000` | Unix 秒／ミリ秒を日時に変換 |
| `utimeAsia/Tokyo` | 有効なタイムゾーンの現在時刻を表示 |
| `udate20261002`、`udate2026-10-02` | 過去日数／残日数／今日と開始日・終了日を表示 |
| `udate20261001.20261002` | 2つの日付の差と開始日・終了日を表示。区切りは `.`, `-`, 空白1つ |
| `uconv5`、`uconv5.5` | 長さ、質量、温度、体積、圧力、電気量の一般的な変換を表示。入力単位を推測しません。 |
| `uconv5mi`、`uconv72f`、`uconv5kg` | 指定単位のカテゴリ内で変換（長さ、質量、体積、温度など） |
| `uconv1000pa`、`uconv1kpa`、`uconv1mpa`、`uconv760mmhg`、`uconv1kgf/cm2` | 圧力単位と静水換算階数を表示します。消防給水がその階数まで届く意味ではありません。`mp`/`mpa` の末尾に 1/2/3 を付けると消防静圧参考値を適用します。1 は既定 0.10MPa（高さ100m超は0.15）、2 は0.07MPa、3 はユーザー参考値0.01MPaです。 |
| `uconv3mH2O`、`uconv3floor` | 水柱高さまたは階数から理論圧力を換算。既定階高は3.0mです。建物の実際の給水能力を示すものではありません。 |
| `uconv220v`、`uconv2a`、`uconv500w`、`uconv10kohm`、`uconv1kwh`、`uconv60hz`、`uconv100uf` | 電圧、電流、電力、抵抗、エネルギー、周波数、静電容量、インダクタンス、電荷を同じ物理量カテゴリ内で変換します。回路公式による推定はしません。`mW`/`MW`、`mWh`/`MWh` など SI 記号は大文字小文字を区別します。 |
| `uconv100rmb`、`uconv100usa`、`uconv100jp`、`uconv100uk` | 主要通貨を換算します。日付付きの参考レートであり、リアルタイム取引レートではありません。ネットワークには通貨コードだけを送信し、入力金額は送りません。別名: `rmb/cn`、`usa/us`、`jp`、`uk`。 |
| `uip` | ローカル IP を表示し、パブリック IP、地域、ISP を検索。ネットワークが必要で、パブリック IP を検索サービスへ送ります。 |
| `uip8.8.8.8` | 入力を少し止めると IPv4 のおおよその地域とプロバイダーを検索します。対象 IP は検索サービスに送信されます。 |
| `u132...`、`uphone132...` | 中国本土の電話番号先頭番号帯を識別します。11桁すべて入力すると、ローカル番号帯データで地域と通信事業者を表示します。個人の現在地や現在の事業者を示すものではありません。 |
| `u+86 171 6772 6019`、`u+86 (21) 6349 3582` | iPhone からコピーした国際形式の携帯／固定電話番号を検索。空白、ハイフン、中国語／英語括弧に対応し、`u021-20422661`、`u02120422661`、`u（021）20422661`、`u(021)20422661` も使えます。ローカル番号帯データのみを使い、番号をアップロードしません。不正形式や長すぎる番号は拒否します。 |
| `umaxwidth600` | パネル最大幅を600ptに設定（範囲200～2000、既定400）。画面の空き幅が優先されます。 |
| `ufloorheight3.2` | 階高設定: `ufloorheight3.2（3.2:階高；設定範囲2～12m；既定3m）` |
| `ufiredefault1-0.15` | 分類1の消防静圧参考値を0.15MPaに設定。分類1～3、0超～2.4MPa。分類3の0.01MPaは規定値ではなくユーザー参考値です。 |
| `ulangzh`、`ulangtw`、`ulangen`、`ulangko`、`ulangja` | パネルの表示言語を切り替えて保存。`ulang` で選択肢を表示します。 |

### 互換性と制限

本ソフトは Squirrel プロセス内のプラグインであり、汎用の文字入力代替ではありません。文書化された対象環境は macOS 26.6.2、Squirrel 1.1.2（同梱 librime 1.17.0）、簡体字入力ソース `im.rime.inputmethod.Squirrel.Hans` です。ビルド対象は macOS 13以降および Universal arm64/x86_64 ですが、他の macOS バージョンはエンドツーエンド検証されていません。候補検索は `~/Library/Rime/default.yaml` の既定スキーマを使います。名前付きのサードパーティースキーマは個別検証されていないため、他のバージョン、入力ソース、スキーマが対応済みとは限りません。

| 機能 | 適用条件 |
| --- | --- |
| `u` パネルの起動 | 指定の Squirrel 簡体字入力ソースを使い、編集欄以外で小文字 `u` を入力します。Squirrel にアクセシビリティ権限が必要です。 |
| ピンイン候補と翻訳 | 独立した Rime セッションと `default.yaml` の既定スキーマを使います。一時的に選択したスキーマが引き継がれる保証はなく、名称のあるサードパーティースキーマは未検証です。 |
| 矢印キーとスキーマのページキー | パネルの矢印キーおよび PageUp/PageDown はパネル内を移動します。独自ページキーはクエリーセッションからバインドを読み取れる場合のみ有効で、既定以外のスキーマの設定は保証されません。 |
| 日時、単位、色形式、幅、電話番号／地域ツール | パネル起動後にクエリーブリッジがローカル処理します。前述の Squirrel/macOS/入力ソース要件は共通です。色選択はシステムカラーピッカーを使い、画面収録権限は不要です。 |
| IP、為替、オンライン翻訳、Web検索 | ネットワークと各サービスに依存します。オンライン翻訳にはプロバイダー設定も必要です。 |

ビルドや単体テストが成功しても、記載されていない環境でのエンドツーエンド互換性を保証するものではありません。
