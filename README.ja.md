# SquirrelTranslate

macOS の Squirrel（Rime）向け翻訳・クイック検索パネルです。候補翻訳、IP と電話番号の地域検索、日付・時刻・単位変換、色ツールを提供します。

言語: [简体中文](./README.md) · [繁體中文](./README.zh-Hant.md) · [English](./README.en.md) · [한국어](./README.ko.md) · [日本語](./README.ja.md)

## 主な機能

- Rime の候補を翻訳し、利用可能な発音記号を表示します。
- 編集可能な入力欄以外で `u` パネルを開き、翻訳や各種ツールを使えます。
- IP の地域情報と中国の電話番号地域を検索し、日付・時刻・単位・色を変換します。
- macOS 辞書、Google、Bing、DeepL API を翻訳に利用します。

## パネル言語の設定

`u` パネルで次のコマンドを入力すると、すぐに表示言語が切り替わり、確認メッセージを表示して設定を保存します。

| コマンド | 言語 |
| --- | --- |
| `ulangzh` | 簡体字中国語 |
| `ulangtw` | 繁体字中国語 |
| `ulangen` | 英語 |
| `ulangko` | 韓国語 |
| `ulangja` | 日本語 |

`ulang` を入力すると選択肢を表示します。この設定は UI とヘルプのみを変更し、候補の翻訳や検索データは変更しません。

## 使用例

| 入力 | 結果 |
| --- | --- |
| `uip8.8.8.8` | IP の地域・ネットワーク事業者 |
| `u132...` または `uphone...` | 中国本土の電話番号地域検索 |
| `udate20261002` | 今日を基準にした日付計算 |
| `utime1727683200` | Unix タイムスタンプ変換 |
| `uconv1000pa` | 圧力などの単位変換 |
| `ucolorRRGGBB` | HEX/RGB/HSL/HSV 色形式変換 |
| `umaxwidth600` | パネル最大幅の設定 |

## インストールと互換性

詳細な[インストール手順](./README.md#安装-u-面板)、互換性表、権限、翻訳プロバイダー設定、トラブルシューティングは中国語 README を参照してください。明記された macOS、Squirrel、Rime の組み合わせのみを検証済みとして扱ってください。

macOS と Squirrel が必要です。Squirrel アプリにアクセシビリティ権限を許可してください。色の取得に画面収録権限は不要です。オンライン機能にはネットワーク接続が必要です。
